
# Grocereo Company Website (Initial Version)

This is the initial static website for **Grocereo**, created to mirror the structure and professional feel of Nexa Technology while delivering grocery‑focused content.

## Structure

```
/
├── index.html
├── about.html
├── services.html
├── dashboard.html
├── contact.html
├── css/
│   └── style.css
└── js/
    └── main.js
```

*The dashboard uses a fresh card‑based layout, differentiating it from the reference site.*

## Getting Started

Open `index.html` in any modern browser. No build tools are required.

Feel free to provide additional guidance, and we can iterate on this foundation.
